## 4. Licensing notes — what we can adapt vs link

### 4.1 Khan Academy Creative Commons (videos & exercises)

Public help guidance (summarized from support articles indexed publicly):

- **License:** Creative Commons **Attribution–NonCommercial–ShareAlike** (**CC BY-NC-SA**) for many Khan-made videos and exercises.  
- **Version note:** Older offline/KA Lite distributions and some GitHub exercise repos cite **CC BY-NC-SA 3.0**; always check the license notice on the specific asset.  
- **Partner content:** Some partner videos/articles are **not** under the same CC license — Terms of Service updates require those to be flagged.

**CC BY-NC-SA obligations if adapting:**

1. **Attribution** to Khan Academy + link to https://www.khanacademy.org  
2. **NonCommercial** — Khan defines commercial to include incorporating content into a **paid offering**, ads, or marketing use. **Prosper Prep paid tuition / scholarships platform = commercial context → adapting KA text/video into our catalog is not a clean NC fit.**  
3. **ShareAlike** — adaptations must be released under the same (or compatible) BY-NC-SA terms.  
4. Required notice language (paraphrased from KA help): *“Note: All Khan Academy content is available for free at www.khanacademy.org”* — and if KA materials appear behind login, that notice must appear **before** login.  
5. No endorsement implication; trademark/brand policy restricts implying official KA affiliation.  
6. Framing / obfuscating KA content behind paywalls or ads is called out as disallowed.  
7. Recent ToS guidance (public summaries): do **not** scrape KA to train AI / build competing services from their data.

### 4.2 Practical Prosper Prep posture

| Action | OK? | Notes |
|--------|-----|-------|
| **Link out** to specific KA lessons as optional enrichment | ✅ Prefer | Clear “free on Khan Academy” label; no framing ads |
| **Topic-align** Prosper Prep scope to KA/IM/CC domains | ✅ | Ideas/standards aren’t copyrighted |
| **Author original** lesson bodies, CER prompts, quizzes | ✅ **Primary path** | Matches existing `grade-6-free-sources.md` |
| **Copy or lightly rewrite** KA articles/exercises into paid courses | ❌ Avoid | NC + ShareAlike + paid offering conflict |
| **Embed** KA videos inside Prosper Prep behind login | ⚠️ Risky | Attribution + pre-login free notice + NC/paid issues — legal review before any embed |
| **Use KA name** in marketing as “powered by” / official | ❌ | Trademark / brand policy |
| Prefer **CC BY** open curricula (OUR/IM, Utah math) + **public domain** (NASA, USGS, many LOC) | ✅ | See `grade-6-free-sources.md` |
| OER Project history materials | ✅ Usually adaptable under OER Project terms (confirm per asset) | Stronger fit than KA NC for text we rewrite into PP |

**Bottom line:** Treat Khan as a **coverage map and optional free link**, not as a content warehouse for Prosper Prep’s paid Grade 6 catalog.

## 5. Prosper Prep–unique pedagogy (not a Khan clone)

### 5.1 Brand anchors

- **Elite online K–12** for **East Texas families**: scholarship pathways + independence, not anonymous mastery grind.  
- **Grade 6 immersive classroom already exists** (`docs/grade-6-classroom-ui.md`): subject islands, Messages, live strip, progress ring.  
- Curriculum must feel like a **school**, not a skill tree: teacher presence, writing, ceremony, report cards, athletic & faith pathways as first-class (not buried under “extras”).

### 5.2 Experience pillars (distinct from Khan)

| Pillar | Prosper Prep | Contrast with typical KA |
|--------|--------------|---------------------------|
| **Classroom hub** | One home base with **subject islands** (ELA, Math, Science, History, Biz, Athletics, Bible) | KA = course catalog / mastery dashboard |
| **Live teacher sessions** | Scheduled live class + “Ask my teacher” DM | Optional; KA is primarily asynchronous self-paced |
| **Messages** | Inbox, announcements, class group, teacher blast | Not a school messaging product |
| **CER writing** | Claim–Evidence–Reasoning as a **cross-subject habit** (Science labs, History DBQ-lite, ELA arguments) | KA practice is mostly discrete skills |
| **Scholarships & report cards** | Visible progress toward scholarship standing / independence goals | Mastery % of skills |
| **Paleo-Hebrew Bible track** | Separate island; not mixed into core ELA | N/A |
| **Athletic pathway** | Separate island; college athletic readiness | N/A |
| **East Texas identity** | Local geography, Texas history touchpoints, family/scholarship narrative | Global neutral brand |

### 5.3 Year-long lesson template (every core lesson)

Use this skeleton so authors and the immersive UI stay consistent:

1. **Learning objective** — one kid-facing “I can…” + teacher standard tag  
2. **Warm-up** — 3–5 min activate prior knowledge / curiosity hook  
3. **Teach** — multi-section explanation: examples, worked model, **explicit misconceptions**  
4. **Guided practice** — we-do / with scaffolds; teacher can drive in live session  
5. **Independent practice** — student set + **answer key for teachers** (not shown to students)  
6. **Exit ticket / quiz** — 3–5 items; feeds gradebook / report-card progress  
7. **Stretch** — optional challenge / CER prompt / real-world East Texas or scholarship-adjacent application  

Optional footer: light **Source note** when scope is deliberately aligned to an open curriculum (OUR/IM, CK, NASA) — never implying Khan endorsement.

### 5.4 Realistic first ship (year depth)

**Target depth:** ~150–180 school days **or** ~30–36 weeks × 4–5 lessons/week ≈ **120–180 lessons** per core subject.

| Priority | Ship scope | Suggested structure |
|----------|------------|---------------------|
| **P0** | **Full Math year** + **full ELA year** | Math: ~8–10 units / ~140–160 lessons (ratios → decimals/fractions → integers → expressions/equations → geometry → stats). ELA: reading/writing/grammar spine ~8–10 units / ~140–160 lessons with weekly CER + grammar islands. |
| **P1** | **Science** + **Social Studies / World History** | Science: Life + Earth spine (~8 units / ~120–140 lessons). SS: age-trimmed world + Texas connections (~8 units / ~120–140). |
| **Parallel (already product islands)** | Entrepreneurship, Athletic Pathway, Paleo-Hebrew Bible | Separate tracks; do not block core ship |

**First content CADENCE (practical):**

1. Author Math Units 1–3 + ELA Units 1–3 at full template depth (prove pipeline).  
2. Expand to full-year Math + ELA outlines (all unit titles + objectives) even if some Stretch/answer keys land in a second pass.  
3. Science + SS outlines next; reuse CER and exit-ticket patterns.  
4. Seed live-session agendas that **reuse** the Teach + Guided practice blocks (teachers don’t reinvent).
