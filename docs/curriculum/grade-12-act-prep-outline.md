# Prosper Preparatory — Grade 12 ACT Preparation (Standalone Course Outline)

**Course code (proposed):** `ACT-12`  
**Status:** Outline v1 — original Prosper Prep content; CC BY / public domain only for any external assets (no NC).  
**Audience:** 12th grade college-prep / athletics-scholarship track; goal = **top-percentile** ACT (composite 33–36 band).  
**Format:** Standalone elective / college-readiness course — **not** bundled with other G12 cores yet.  
**Assessment backbone:** ACT-style multiple choice + timed sections; value-add constructed responses for reasoning (math explanations, science write-ups, English grammar “fix & justify”).

## Course goal & progression path

```
Diagnostic full ACT (Form A)
    → Score report + weakness map (English / Math / Reading / Science [/ Writing])
    → Targeted skill building (content + advanced strategy)
    → Timed section drills (single section, real pacing)
    → Mini mixed sets (2-section combos)
    → Full practice exams (Forms B–D)
    → Score review + personalized improvement plan
    → Final Form (or retake Form D under test-day conditions)
```

**Top-percentile emphasis:** Every unit ends with *strategy layer* (pacing budgets, elimination trees, when to guess, passage mapping, experiment-variable charts)—not content review alone.

## Shared instructional model

| Element | Role |
|---|---|
| Study guide | Strategy, timing, question types, traps, scoring |
| Video (scripted) | Khan-style original PP video: teach → worked example → “your turn” pause point |
| Topic quiz | 8–15 ACT-style items; 1–2 short written justifications where useful |
| Section drill | Timed authentic length for that ACT section |
| Full practice test | 4-section timed battery (+ optional Writing) |
| Improvement plan | Auto + teacher review after each full form |

**Suggested grade weights (course):** Diagnostics/practice tests 40% · Section drills 20% · Topic quizzes 20% · Strategy write-ups / labs 10% · Final improvement portfolio 10%.

**Licensing:** All passages, items, diagrams, and scripts = original Prosper Prep **or** CC BY / public domain. No rehosted ACT Inc. forms, no NC OERs inside the paid LMS. Official ACT practice = link or licensed PDF outside remix.

# MODULE E — ACT English (Weeks 2–5)

**Official shape:** 75 questions / 45 minutes · 5 passages · Usage/Mechanics + Rhetorical Skills.

### Study guide
- Question-type breakdown: grammar/usage, punctuation, sentence structure, strategy, organization, style
- Timing: ~36 seconds/question; passage-first vs question-first
- Traps: “could be right” vs “best”; redundancy; distraction; idiom
- Advanced: answer-in-context; read enough / not too much; vertical scan of choices

**Unit E3 — Rhetorical skills**
| Lesson | Video |

- Topic quizzes E1–E3 (10–12 items each + 1 “fix & justify” grammar write-up)

### Live prompts

# MODULE M — ACT Math (Weeks 6–9)

**Official shape:** 60 questions / 60 minutes · Pre-Algebra → Algebra → Geometry → some Trigonometry; increasing difficulty trend.

### Study guide
- Content map by ACT reporting categories
- Timing: 60 sec average; front-load easy points; mark & return
- Calculator: when it helps vs slows; mental math shortcuts

# MODULE R — ACT Reading (Weeks 10–12)

**Official shape:** 40 questions / 35 minutes · 4 passages (Literary Narrative, Social Science, Humanities, Natural Science).

### Study guide
- Passage types & common structures
- Timing: ~8–9 minutes per passage block
- Question families: detail, inference, main idea, vocab-in-context, author method, comparative (paired)
- Traps: too extreme; true but not in passage; half-right; inverted causality
- Advanced: **passage mapping** (margin structure tags); question stem before deep re-read; evidence windows

# MODULE S — ACT Science (Weeks 13–15)

**Official shape:** 40 questions / 35 minutes · Data Representation, Research Summaries, Conflicting Viewpoints *(confirm current ACT Science format annually—adjust if ACT updates)*.

### Study guide
- Science on ACT = reasoning with figures, not memorized AP content
- Timing: ~5 minutes per passage/set average; don’t over-read stems
- Traps: mixing studies; wrong axis; outside knowledge overriding data
- Advanced: variable charts; highlight controls; predict before looking at choices; conflicting-viewpoints claim map

### Study guide

- Timing: 5 plan / 30 write / 5 spare polish

# MODULE P — Full Practice Exams & Improvement (Weeks 17–18)

| Form | When | Purpose |
|---|---|---|
| **A** | Week 1 | Diagnostic |
| **B** | Week 17 | Mid-course full under test-day rules |
| **C** | Week 18 early | Peak attempt |
| **D** | Week 18 / extension | Final confirmation or makeup |

Each full form includes:
- Timed sections (strict)
- Immediate raw → estimated scale report (PP concordance table; *not* official ACT)
- Section error log (content tag + trap type + timing flag)
- **Improvement plan** template: top 3 levers before next test date

### Closing portfolio (graded)
1. Score trajectory chart (A→B→C)
2. Written reflection (1 page): what strategy changed composite most
3. Next official ACT date plan (registration checklist link-out)

### Live / discussion
- “If you only fix one section before test day, which one moves composite most—and why?”
